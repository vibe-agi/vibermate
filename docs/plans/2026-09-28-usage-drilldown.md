# 用量报表：分层明细与项目归属

本次发版先修复持续 503，再加入用户确认的用量明细。保持 v1 契约；复用现有统计账本、计价和权限隔离，不增加依赖。

## 页面

受众是本地 App、本地 Web 和登录 Runtime 的使用者。页面只回答：谁、在哪个项目/分支、用哪个模型，产生多少请求、Token 和 API 等价费用。

```text
期间 / 统计设置
总调用、成功、失败、输入、输出、API 等价费用
每日请求 / 估算费用趋势

明细：策略 / 上游账号 / 模型 / 来源 / 调用者 / Git 项目
当前层级说明：Git 项目 › 启动分支 › 调用者 › 模型
名称                         调用  失败  输入 Token  缓存读取  输出 Token   估算 USD
▾ repository                 ...                                          $...
  ▾ main                     ...                                          $...
    ▾ alice                  ...                                          $...
        model                ...                                          $...
总计                         ...                                          $...
```

- 策略、上游账号、来源展开为模型；模型展开为调用者；调用者展开为模型；Git 项目展开为启动分支、调用者、模型。
- 六个维度复用一张可展开表格，不堆叠新卡片。父行是小计，子行是构成，总计从报表读取，绝不把展开行重复相加。
- 名称左对齐，数值右对齐、等宽数字。表格使用完整千位分隔数，概览保留 K/M；USD 两位小数。真实零、未知 `—`、不完整下限 `≥` 分开。
- 费用列加字重；子行缩进、轻背景与层级图标体现结构；标题/路径标明每一层的含义。窄屏保持统一列宽并横向滚动，展开按钮支持键盘、语义标签与 tooltip。
- 复用主题：画布 #10151A、面板 #182028、分隔 #303C47、正文 #F1F5F8、数据蓝 #75B8F0、警示黄 #E5B663；系统标题与正文，数字使用 tabularFigures。亮色直接使用已有主题。
- 设计复核：报表的重点是可核对的小计和费用，不是装饰图表；不引入全新视觉系统或重复 KPI。

## 归属与真实性

- 调用者按用户确认：已认证 Runtime 用户优先；本机使用者为启动器已有的显示元数据，不等同身份认证，不用于授权；其键与机器作用域绑定。
- 不按 Git author/committer 推测使用者，不读取邮箱、远端 URL、凭据、文件内容或对话正文。
- Git 在启动器一侧只读采集仓库标识、名称、分支快照。明确称为“启动分支”；不在历史报表查询时读取当前工作树，不将今天的分支回填到旧请求。
- 相同本机仓库的子目录/worktree 合并，不同机器/克隆不凭同名合并。Detached HEAD 独立标识。未安装 Git、非仓库、旧记录缺失均显示未知。
- 采集失败不能阻止 Agent 启动。Git 调用有时限、不联网、不运行 shell 或 hooks；报告只含不透明 ID 与短标签，不包含绝对路径。
- 新的用量观察在落库时冻结已有 Capture 的归属，继续服从 Runtime 统计开关与期限；旧观察只利用已有稳定 Capture 归属，不补造 Git 历史。
- 所有分组在用户权限过滤之后计算；明细和费用共用逐请求结果。限制返回的明细数量，截断时显式标注，不伪装成完整合计。

## 验证

- 503：原生会话身份不被历史消息作者覆盖；旧索引不一致仍返回有效记录并触发已有后台修复；加载失败不显示为零/未绑定。
- Git：子目录、worktree、普通分支、未提交新仓库、detached、非仓库、超时/取消、启动时快照与后续切分支隔离。
- 统计：各层请求/Token/费用与父层一致、失败及缺失值、调用者权限隔离、旧记录/删除/留存、重启持久化。
- UI：展开/折叠与刷新稳定、表格数字表达、390/1440 宽度、亮/暗、中/英布局和截图。
- 所有检查通过后再推送、发布 v0.1.15、更新 Homebrew；不替换运行中的本地 App。

## 实施结果

- 503 的可复现根因是原生 Codex 会话/线程身份被历史消息作者覆盖。共享投影已改为原生身份优先；旧投影缺少一致的附加身份时仍返回有效记录，既有有界后台索引可以恢复。页面保留已读策略与旧详情，失败不冒充空记录，后台每 5 秒重试并清除恢复后的错误。
- 六个维度共用逐请求聚合与计价。每维最多 5,000 个层级节点，达到上限明确标注部分明细，父层和总计继续累加；不因展开而重复计费。
- Git 采集只读、有 1 秒时间和 8 KiB 输出限制，不受环境中的 GIT_DIR 重定向；仓库标识按机器分域。元数据使用可恢复的附加存储，不重置既有数据库，删除 Capture 时关联删除。
- Go 全量测试、vet、发布构建和结构检查通过；会话/详情/存储/启动器/统计 race 回归通过。Flutter 全量 649 项通过、16 项跳过；最后的详情恢复、报表层级和契约回归 102 项通过。
- 已检查 390/1440 宽度、中英文、深浅主题截图。表格使用完整数字与 USD 两位小数，极小完整金额以 `< $0.01` 表示；金额详情保留精确值与计价覆盖。刷新不丢失展开状态。
- 发布前 CI 暴露两处遗漏：截图配置只在本机读取，Chrome 保留全部布局断言；压缩流关闭先中断传输，再等待当前 Read 退出后释放解码器，避免 zstd 的并发关闭竞态。Chrome/桌面布局测试通过，压缩与关闭 race 回归连续 50 次通过。
