## 中文

ViberMate 0.1.14 是第一阶段稳定版，重点收敛性能、操作边界、诊断和团队部署体验。

- 大型会话、长正文和远程 Web 改为有界增量加载；减少无变化轮询、重复解码和连带重建。
- 上游账号从 Environment 独立管理。Codex OAuth 与 `auth.json` 导入使用同一套托管刷新逻辑，并提供明确的额度、历史用量和充值重置券操作。
- Environment 发布前可试跑账号、模型、协议和字段变化；单个请求固定使用已选账号，不会在失败后暗中切换或重放。
- Owner 可在本机或远程 Web 创建、轮换和撤销手动代理登录，并交付对应 Proxy CA；Server HTTPS 证书与 Proxy CA 保持独立。
- 新增跨运行记录检索、原始 HTTP 阶段比较、可预览脱敏诊断、存储占用说明及可验证备份恢复。
- ACP 观察作为实验性能力随 App、Server 和 CLI 一起提供；它观察编辑器协议，不继承 HTTP 路由、账号或脚本策略。
- 删除用户可见的 Offline Hold。ViberMate 不承诺暂停任意 CLI 超时，只保留请求外发所需的内部准入边界。
- 设置页按 App、Runtime Server 和 Terminal command 显示版本，仅在用户点击时检查官方 GitHub Release，并按 Homebrew、手动安装或 Server 部署给出更新步骤。
- 项目改为 AGPLv3，并提供独立商业许可和专业服务说明；AGPLv3 不禁止企业或商业环境使用。

默认 Full 录制会按保留期保存语义请求和响应正文。透明代理只能说明观察到的网络数据，不能可靠推断本地文件路径，也不能解密客户端在应用层自行加密的载荷。

macOS 14+（Apple silicon / Intel）：

```sh
brew update
brew install --cask vibe-agi/tap/vibermate
# 已安装：brew upgrade --cask vibe-agi/tap/vibermate
```

Linux x86_64 / arm64 压缩包包含 Server、CLI 和 Web 工作台。请按 `SHA256SUMS-linux` 校验下载。

## English

ViberMate 0.1.14 is the phase-one stable release focused on measured performance, explicit authority boundaries, actionable diagnostics, and team deployment.

- Bound and incrementally load large conversations, long bodies, and remote Web assets; avoid unchanged polling, repeated decoding, and unrelated rebuilds.
- Manage upstream Accounts independently from Environments. Codex OAuth and `auth.json` imports share managed refresh behavior, with explicit quota, history, and banked reset-credit actions.
- Dry-run Account, model, protocol, and field changes before publishing an Environment. A request keeps its selected Account and is never silently switched or replayed after failure.
- Let an Owner create, rotate, revoke, and deliver manual proxy logins and the Proxy CA from local or remote Web. Server HTTPS identity remains separate from the Proxy CA.
- Add cross-Capture search, Raw HTTP stage comparison, previewed redacted diagnostics, storage disclosure, and verified backup/restore.
- Ship ACP observation as an experimental App/Server/CLI capability. It observes the editor protocol and does not inherit HTTP routing, Account, or script policy.
- Remove the user-facing Offline Hold claim. Internal request admission remains, but ViberMate does not promise to pause arbitrary client timeouts.
- Show App, Runtime Server, and Terminal command versions. Update checks are explicit and use the official GitHub Release; instructions follow the detected install channel.
- License the project under AGPLv3, with separate commercial licensing and professional services information. AGPLv3 does not prohibit business use.

Full recording is the default and retains semantic request and response bodies for the configured retention period. A transparent proxy can describe network bytes it observed; it cannot reliably infer local file paths or decrypt payloads encrypted by the client at the application layer.

The exact macOS DMG completed Developer ID signing, Apple notarization/stapling, Gatekeeper assessment, and two isolated installed-App launches in the [protected release workflow](https://github.com/vibe-agi/vibermate/actions/runs/36216643296). The x86-64 and ARM64 archives passed the [Linux release workflow](https://github.com/vibe-agi/vibermate/actions/runs/36217553631) and published checksums. These checks do not claim live-provider compatibility beyond the explicitly tested boundaries.
