# ViberMate 0.1.26

Phase B candidate preparation for App/Runtime/CLI `0.1.26+28`. Signed distribution, installed-candidate acceptance and protected public-release checks remain pending.

## Highlights

- Configure upstream VLESS, including REALITY + Vision, and use ViberMate's authenticated SOCKS5 listener for TCP and supported UDP traffic.
- Enter one direct domain per line, including `localhost` and wildcard subdomains. Matches use System DNS and Direct on the Runtime machine; `localhost` refers to that machine. This list accepts domains, not IP/CIDR rules, and grants no target access.
- Set a global default exit. Explicit account or flow exits override it, including explicit Direct. New operations inherit changes; in-flight operations keep their route, and failed proxies do not fall back.
- Shared quota and credit refresh defaults to five minutes. Manual refresh is immediate; failures retain the last successfully fetched data.
- Short Runtime reconnect diagnostics no longer corrupt a child's interactive input. The released account reauthorization, Web session refresh, default HTTP/HTTPS port and long-session fixes remain.
- Upstream CA trust applies only to its configuration. It is separate from the interception CA and does not bypass REALITY identity verification. Trusted helper distribution remains subject to candidate package integrity and release checks.
- Startup upgrades use the existing verified private backup and migration path to preserve accounts, configuration and history. Public backups omit credentials and other secrets; their exclusions do not describe private migration preservation. No data reset is required by these notes.

## Limits and delivery

Remote raw SOCKS requires a trusted, reachable network and a UDP-capable client for UDP. Its traffic is not encrypted by the HTTP run relay, and that relay is not a UDP tunnel. Full active MCP continuation and the full 46-client matrix are not claimed complete. Windows native UDP, untested mobile/platform abilities and broader Phase C qualification remain unqualified. These candidate notes do not establish a signed package or completed public delivery.

## 中文说明

- 可配置 VLESS 上游（包括 REALITY + Vision），并通过 ViberMate 自有、需认证的 SOCKS5 监听器传输 TCP 和受支持的 UDP 流量。
- 每行填写一个直连域名，可包含 `localhost` 和通配子域名。匹配后在 Runtime 所在机器上使用系统 DNS 并直连；`localhost` 指该机器。此列表不接受 IP/CIDR 规则，也不授予目标访问权限。
- 可设置全局默认出口；账号或流量策略明确指定的出口优先，包括明确指定 Direct。新操作采用更新后的设置，进行中的操作保留原路由；代理失败不会回退到其他出口。
- 共享额度与 credit 余额默认每五分钟刷新，手动刷新立即执行；刷新失败时保留上次成功获取的数据。
- 短暂的 Runtime 重连诊断不再干扰子进程的交互输入。已发布的账号重新授权、Web 会话刷新、HTTP/HTTPS 默认端口及长会话修复继续保留。
- 上游 CA 信任仅作用于对应配置，与流量拦截 CA 分开，也不会绕过 REALITY 身份验证。可信辅助程序的分发仍须通过候选包完整性及发布检查。
- 启动升级使用现有已验证的私有备份与迁移流程，保留账号、配置和历史。手动导出的常规备份会排除凭据等秘密信息，这些排除规则不代表私有迁移的保留范围；本说明不要求重置数据。

远程原始 SOCKS 需要可信且可达的网络，UDP 还需要支持 UDP 的客户端。HTTP run 中继不会为原始 SOCKS 流量加密，也不是 UDP 隧道。完整的活动 MCP 续接及全部 46 客户端矩阵尚未宣称完成；Windows 原生 UDP、未经测试的移动端或平台能力及更广泛的 Phase C 验收仍未获得资格确认。当前为 `0.1.26+28` 候选准备，签名分发、安装验收和受保护的公开发布检查尚待完成，不代表已公开交付。
