## 中文

ViberMate 0.1.10 优化 App 和 Web 中压缩 HTTP 正文的阅读体验。

- 点击原始 HTTP 的“显示原文”后，完整的 `zstd` / `gzip` Body 默认以解压后的内容显示，可以直接复制正文，不再需要阅读压缩 Base64。
- 正文优先展示；Headers、原始压缩字节和流式帧收纳到 HTTP 详情中。仍可检查原始记录，字节数、摘要和帧偏移保持原始含义。
- 明确提示证据不完整、压缩数据损坏、不支持的编码和解压大小限制，不把无法解压的内容伪装成正常正文。解压阅读上限为 4 MiB。
- 解压仅发生在已授权、已审计的查看操作中，不修改历史证据或额外保存一份解压内容；隐藏正文或离开视图时清理原始与解压缓冲区。
- 增加压缩请求经过消息脚本替换正文的回归测试。路由、账号选择、脚本执行及内容记录策略的行为不因阅读方式改变。

这次不包含 ACP 支持，也不修改已有账号、代理、流量策略或历史记录。

### 已知限制

- 用户报告的 `provider_transport_failed` 尚未在本机复现，本版本不宣称修复该问题。
- Codex 0.153.4 的部分启动参数组合仍有兼容性问题；上游额度错误也可能被 Codex 显示为流中断并重试。本版本不包含这两项修复。
- 本机真实 Codex 原账号接入与隔离 Runtime 对话记录测试通过；所测替换账号返回 `429 usage_limit_reached`，因此不宣称所有替换账号或模型均可用。

macOS 14+（Apple silicon / Intel）更新：

```sh
brew update
brew upgrade --cask vibe-agi/tap/vibermate
```

首次安装使用 `brew install --cask vibe-agi/tap/vibermate`。Linux x86_64 / arm64 压缩包包含 Server、CLI 和 Web 工作台。下载后请校验对应的 SHA256SUMS 文件。

## English

ViberMate 0.1.10 makes compressed HTTP bodies readable in the App and Web workbench.

- Revealing a complete `zstd` / `gzip` body now shows decoded content first, with a dedicated copy-body action instead of compressed Base64.
- Keep headers, original compressed bytes, and stream frames in expandable HTTP details. Original byte counts, digests, and frame offsets retain their original meaning.
- Explain incomplete evidence, corrupt compression, unsupported encodings, and the 4 MiB decoded-view limit instead of presenting undecodable bytes as normal text.
- Decode only during an authorized, audited reveal. Do not rewrite retained evidence or persist an additional decoded copy. Clear both body buffers when hidden or disposed.
- Add regression coverage for script replacements on compressed requests. Routing, account selection, transforms, and recording policies are unchanged by the reading view.

Existing accounts, proxy settings, traffic policies, and history are unchanged. ACP support is not included.

### Known limitations

- The reported `provider_transport_failed` has not been reproduced locally; this release does not claim to fix it.
- Some Codex 0.153.4 launch-argument combinations still have compatibility issues. Upstream quota errors can also appear as stream disconnections and trigger Codex retries. Neither issue is fixed in this release.
- Live local Codex tests with the original account and an isolated Runtime passed. The tested replacement account returned `429 usage_limit_reached`; this does not establish availability for every replacement account or model.

For macOS 14+ (Apple silicon / Intel), run `brew update`, then `brew upgrade --cask vibe-agi/tap/vibermate`. First installation: `brew install --cask vibe-agi/tap/vibermate`.

Linux x86_64 / arm64 archives include the Server, CLI, and Web workbench. Verify downloads against the corresponding SHA256SUMS file.
