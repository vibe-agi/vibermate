# ViberMate 0.1.18

Published 2026-09-29 from `25091f8` ([release](https://github.com/vibe-agi/vibermate/releases/tag/v0.1.18)).

## Highlights

**Self-contained Web workbench**
- The Web workbench no longer loads anything from a third-party site. The Flutter rendering engine (CanvasKit) and all fallback fonts now ship inside the release. Each font is checked against a pinned SHA-256 and ships with its license text.
- The workbench now works on offline and private-network servers. Opening it contacts only your ViberMate server.
- The server sends a strict Content-Security-Policy, so the browser refuses anything that isn't served by ViberMate.
- On the Web, Chinese labels no longer get clipped because a font arrived late.

**Documentation**
- The deployment, Docker and backup guides are now available in English and Chinese.
- The guides now match the product. By default, conversations are recorded and kept for 30 days. Server addresses need an explicit port.
- The product page at vibe-agi.github.io now explains ViberMate step by step, with current screenshots.
