# ViberMate 0.1.27 (29) — Codex startup hotfix

Fixes Codex startup failing with `account/read failed: workspace routing discovery failed` when a traffic policy uses a managed model account.

ViberMate now resolves and freezes the network exit for the client's original-credential startup probes before forwarding them. This preserves the client's login identity, existing proxy precedence and in-flight routing; failed proxies do not silently fall back to Direct.

The regression is verified with Codex 0.161.0 startup, managed quota/history reads, request isolation and failure cleanup. This is a focused patch on 0.1.26: no new database migration, account reset, history cleanup or unrelated feature is included.

## 中文说明

修复使用托管模型账号时，Codex 在启动阶段报 `account/read failed: workspace routing discovery failed`、无法进入对话的问题。

补齐启动探测请求的网络出口解析，保留 Codex 原登录身份和既有代理优先级；进行中的请求不换路，代理失败不偷偷直连。已使用 Codex 0.161.0 验证启动及后续账号读取。

本版基于 0.1.26，仅包含此 Hotfix；不新增数据库迁移，不清理数据，不要求重新登录或导入账号。升级后重新打开 ViberMate，再重新运行原来的启动命令。
