# ViberMate 0.1.35 (37) — Agent network recovery and workbench fixes

Improve the shared proxy path used by Agent CLIs, including Codex and Claude:

- Release pending Runtime connections when the client disconnects, while keeping established tunnels and streaming responses under their existing lifetimes.
- Give other resolved addresses a chance when one address stalls, and bound complete proxy connection setup to 30 seconds unless the caller has an earlier deadline.
- Recreate a VLESS helper that has exited when a later operation needs it. A failed request does not restart a healthy helper or replay model traffic.
- Report unavailable account model-capability discovery as a retryable service failure. A verified incompatible Daybreak/model selection remains a configuration error.

Fix persistent history conflicts caused by SQLite creating an empty WAL beside a checkpointed archive. This could prevent Capture details, usage reports and storage statistics from loading. Usage snapshot changes now retain their conflict response instead of appearing as a generic Runtime outage.

Account controls now share one shape with hover and keyboard-focus feedback. Points balances use compact icons and numbers, and Daybreak/Standard model capabilities appear in separate groups.

Existing authorization, explicit network-exit selection, credential scope and in-flight request ownership remain enforced. No storage schema change is included. Existing [backup and rollback boundaries](https://github.com/vibe-agi/vibermate/blob/v0.1.32/docs/backup-and-restore.md#format-compatibility-and-rollback) continue to apply.

## 中文说明

改善 Codex、Claude 等 Agent CLI 共用的代理链路：

- 客户端断开后及时释放仍在等待的 Runtime 连接；已建立的隧道和流式响应保留原有生命周期。
- 某个解析地址连接停滞时，为同一目标的其他地址保留连接时间。完整代理连接建立过程上限为 30 秒；客户端更早的截止时间仍然生效。
- VLESS 辅助进程退出后，后续操作可以重新建立它。单次请求失败不会重启正常工作的辅助进程，也不会重发模型请求。
- 模型能力查询暂时失败时，返回可重试的服务错误；已确认的 Daybreak 模式与模型不兼容仍按配置错误处理。

修复历史库读取持续报错：SQLite 正常创建空 WAL 文件时，不再被误判为历史发生变化。此前此问题可能导致运行详情、用量报表和存储统计持续无法加载。用量快照变化也会保留明确的冲突响应。

账号启用按钮统一样式并增加悬停和键盘焦点反馈；积分余额使用紧凑图标与数值；Daybreak 和 Standard 模型支持情况分组展示。

本版不改变存储格式。所选出口、权限、账号凭据及在途请求的归属继续保持明确。
