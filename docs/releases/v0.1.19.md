# ViberMate 0.1.19

Published 2026-09-29 from `07bd4e7` ([release](https://github.com/vibe-agi/vibermate/releases/tag/v0.1.19)).

## Highlights

**IP allowlist for the Runtime Server**
- As the Owner, choose which networks may connect in **Settings → Access & launch → IP allowlist**: one address or CIDR network per line. Saving applies at once to the Web workbench, sign-in and Agent traffic, and disconnects connections the new list no longer allows.
- You can't lock yourself out. A list that would disconnect you is refused, the Server machine itself is always allowed, and `vibermated server ip-allowlist clear` on the Server machine restores access within seconds.
- Refused clients are disconnected before TLS or HTTP. The panel shows the address the Server sees for your browser and how many connections it refused.
- Clients are judged by their TCP address. HTTP headers such as `X-Forwarded-For` are never trusted, because anyone can send them.
- Behind a layer-4 load balancer that hides client addresses, turn on PROXY protocol on the load balancer and start the Server with `--trusted-proxies <load balancer subnet>`. With Docker, set `VIBERMATE_TRUSTED_PROXIES` instead. If the load balancer is misconfigured, the Server refuses access rather than allowing it, and the panel shows why.
- Automatic HTTPS keeps renewing certificates while the allowlist is active.

See the [deployment guide](https://github.com/vibe-agi/vibermate/blob/main/docs/deployment.md#limit-who-can-connect-ip-allowlist) for load balancers, Docker and tunnels.

## 中文说明

**Runtime Server 的 IP 白名单**
- 所有者可以在 **设置 → 接入与启动 → IP 白名单** 中选择允许连接的网络，每行一个地址或 CIDR 网段。保存后立即对 Web 工作台、登录和 Agent 流量生效，不再被允许的现有连接会被断开。
- 不会把自己锁在外面：会断开你自己的列表不能保存；Server 所在的机器本身始终允许访问；在 Server 机器上运行 `vibermated server ip-allowlist clear` 几秒内即可恢复访问。
- 被拒绝的客户端在 TLS 或 HTTP 之前就被断开。面板会显示 Server 看到的你的浏览器地址，以及已拒绝的连接数。
- 客户端按 TCP 地址判断。`X-Forwarded-For` 这类 HTTP 头任何人都能伪造，所以一律不信任。
- 如果前面的四层负载均衡会隐藏客户端地址，请在负载均衡上开启 PROXY protocol，并用 `--trusted-proxies <负载均衡网段>` 启动 Server；使用 Docker 时改为设置 `VIBERMATE_TRUSTED_PROXIES`。负载均衡配置错误时，Server 会拒绝访问而不是放行，面板也会说明原因。
- 启用白名单后，自动 HTTPS 仍会照常续期证书。

负载均衡、Docker 和隧道的情况请看[部署指南](https://github.com/vibe-agi/vibermate/blob/main/docs/deployment.zh-CN.md#限制可以连接的网络ip-白名单)。
