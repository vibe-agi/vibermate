# ViberMate 0.1.25

Candidate preparation for App/Runtime/CLI `0.1.25+27`. Publication remains pending the protected release gates.

## Highlights

- Accept HTTP and HTTPS URLs that omit their default ports (`80` and `443`).
- Keep a valid Web login session after a refresh in the same tab, without saving passwords.
- Sign in again with the original OAuth account while preserving its account ID, settings and links. A different identity or a cancelled sign-in does not overwrite the account. Explicitly disabled accounts are not enabled automatically.

## 中文说明

- 支持省略默认端口的 HTTP 和 HTTPS 地址（分别为 `80` 和 `443`）。
- Web 在同一标签页刷新后保留有效登录会话，不保存密码。
- 可以使用原 OAuth 账号重新登录，并保留账号 ID、设置和关联。使用不同身份或取消登录不会覆盖原账号；明确禁用的账号不会被自动启用。

## Verification boundary

These notes describe the scoped candidate changes. They do not claim live-provider qualification or a completed publication. Signed distribution, installed-candidate acceptance and protected release checks remain required before publication.
