# ViberMate 0.1.37 (39) — Continue sessions after tool updates

- Fix native OpenAI Responses conversations failing with `invalid_exchange_request` after Codex resumes or updates tool declarations. Historical redefinitions now update the inspection catalog instead of producing duplicate tool/namespace errors.
- Preserve the complete original conversation and incremental tool declarations when forwarding to a matching Responses upstream. Unchanged namespace members remain available; malformed or duplicate declarations within a single update remain rejected.
- This release includes PR #70 and the previously merged maintenance changes. Transparent capture remains under development in draft PRs #69 and #71 and is not included.

Upgrade the Desktop App, or the Runtime Server used by the CLI, then retry the existing conversation. Session history does not need to be deleted. The fix was verified with regression tests and an offline replay of the affected session; it does not claim that every future client format is supported.
