## 中文

ViberMate 0.1.13 完善环境变量控制、账号关联和数据读取体验。

- 子进程环境变量采用紧凑的双签页：勾选「不传给 Agent」，或「添加 / 覆盖」。支持搜索、疑似凭据提示、手动补充变量名；切换或刷新快照不会清空规则。
- 启动快照来自实际启动 CLI，只传变量名，不上传变量值；按需读取、限量保存在内存中。代理、信任及 ViberMate 管理的变量锁定显示。
- 修复流量策略与账号关联的校验、发布和删除边界，改善空白账号选择状态；将控制接口错误转为可理解的中英文提示。
- 修复 Codex 账号查询端点适配，区分额度查询与需单独授权的历史用量；提醒导入 auth.json 后停止使用原文件进行刷新，避免令牌轮换冲突。
- 优化会话索引和 SQLite 查询，避免反复加载完整对话；页面不可见时暂停自动刷新。
- 设置页展示运行时数据目录与 SQLite 位置。本机 App 支持安全迁移整个数据目录，包含离线检查、内容校验和启动失败恢复；远程 Web 明确显示服务器路径。
- 改善表单标签截断、紧凑复选框和窄窗口布局。

### 使用边界

- 环境变量规则在发布策略后的下一次启动生效，不修改系统环境或正在运行的 Agent。屏蔽环境变量不等于沙箱；疑似凭据识别不保证发现全部密钥。
- 快照不是终端实时状态，重启运行时后清空；通过 ViberMate 再启动一次可更新快照，已有规则不受影响。
- Codex OAuth 是实验性兼容能力。透明代理不修改 CLI 本地 auth.json，CLI 显示的本地身份仍可能与路由账号不同。
- ACP 不包含在本次发布。

macOS 14+（Apple silicon / Intel）：

```sh
brew update
brew install --cask vibe-agi/tap/vibermate
# 已安装：brew upgrade --cask vibe-agi/tap/vibermate
```

Linux x86_64 / arm64 压缩包包含 Server、CLI 和 Web 工作台。请按对应 SHA256SUMS 文件校验下载。

## English

- Add a compact child-environment editor with explicit blocking, overrides, search, credential-name hints, and manual rules. Refreshing or switching snapshots preserves selections.
- Observe names from the actual launching CLI, never server environment values. Snapshots are name-only, bounded, in-memory and read on demand; runtime-managed variables remain locked.
- Fix policy/account relationship validation and lifecycle consistency. Replace blank selectors and raw control errors with actionable localized states.
- Correct supported Codex account-read endpoints; distinguish quota reads from separately authorized history. Warn about refresh-token ownership after importing auth.json.
- Reduce SQLite and conversation-index read costs, avoid repeatedly loading complete transcripts, and suspend hidden-page refreshes.
- Display actual runtime storage paths. The local App can move its entire data directory with offline checks, content verification and startup rollback. Remote Web displays server-side paths explicitly.
- Improve clipped field labels, compact checkboxes and narrow layouts.

Environment rules apply to new launches after policy publication, not existing processes or system settings. They are not sandbox isolation. Snapshots disappear on runtime restart; stored rules remain. Codex OAuth remains experimental, local CLI identity is not rewritten, and ACP is not part of this release.
