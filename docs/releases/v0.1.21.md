# ViberMate 0.1.21

Published 2026-09-30 at 16:37 UTC from `9b7eeaa` ([release](https://github.com/vibe-agi/vibermate/releases/tag/v0.1.21)). macOS App 0.1.21 (23), Runtime/CLI 0.1.21.

## Highlights

- Conversation-first reading: verified user input and Agent text stay on the main reading path. Tool arguments/results, visible reasoning summaries, system/developer context, input history and raw protocol evidence have separate, message-local entry points.
- A reserved side inspector on wide screens does not reflow the conversation. Narrow screens show a returnable detail view. Reading position, inspection tabs and expanded long content survive switching; new replies do not replace the evidence being read.
- Compact, inline Token/API-equivalent cost evidence uses real collected request usage. Details distinguish uncached input, cache reads/writes, output and reasoning subsets. Partial or unavailable evidence is not presented as zero, and loaded-request totals are not advertised as complete conversation totals.
- Fix repeated Codex `idle timeout waiting for SSE` reconnects when native upstream `keepalive` events were buffered by the response decoder. Heartbeats now pass promptly while tool approval/rejection barriers remain intact. No longer timeout or hidden retry policy is introduced.

## Upgrade notes

- Update and restart the App or deployed Server to load the new binaries. Finish or stop active Captures before upgrading; this release does not restart them automatically.
- SQLite schema revision 1 is unchanged. Existing content-recording and usage-collection choices are preserved. Saving the usage-collection switch itself does not require a restart and does not backfill disabled periods.
- Token and cost evidence depends on retained Runtime usage and available pricing. API-equivalent estimates are not the actual subscription bill.
- Automated Codex acceptance uses official Codex 0.159.2 against an isolated localhost fixture without real credentials. It proves the reproduced heartbeat failure is fixed, not that every upstream network outage can be eliminated.
