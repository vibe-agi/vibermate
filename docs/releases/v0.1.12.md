## 中文

ViberMate 0.1.12 集中完善上游账号管理和 App / Web 工作台体验。

- 新增 Codex OAuth 登录（实验性）、授权文件导入和手动填写三个账号入口。开始登录只生成授权链接，由用户选择复制或打开；支持远程浏览器回调。
- 独立的「上游账号」页面集中管理凭据，上游服务通过关联复用账号，不再重复创建凭据。
- 托管 Codex OAuth 刷新，支持手动刷新；替换账号时同时更新 Authorization 和 ChatGPT-Account-Id。
- 展示令牌中的邮箱、套餐和时间信息，并提供按账号查询上游额度及历史用量的入口。历史用量与 ViberMate 本地统计明确区分。
- 为支持的 Codex 账号查询增加服务适配器：固定账号路由下，支持的上游额度查询使用所选账号；历史查询需要单独授权，动态或歧义路由不会猜测账号。
- 账号名旁可快速添加备注，支持搜索、修改和清空；备注独立保存，不改变凭据或流量策略。失败重试保留输入，并防止并发覆盖。
- 精简重复说明，将背景信息移入可点击的帮助按钮；错误、安全提示和操作前提仍直接显示。
- 优化初始窗口尺寸和小屏布局，增加恢复推荐窗口大小的菜单操作，保留用户已保存的窗口偏好。
- 修复 TLS 握手取消时的错误归因，避免连接关闭错误掩盖用户取消原因。

### 使用边界

- Codex OAuth 属于实验性兼容能力，不代表 OpenAI 官方集成或稳定公开 API。上游登录方式和端点可能变化。
- 导入授权文件后，请避免其他工具同时刷新同一份 refresh token；令牌失效时需要重新登录或导入。
- 透明代理不会修改 Codex 的本地 auth.json；原生界面中的本地登录身份仍可能与路由选择的账号不同。
- 令牌资料仅用于展示，不是 JWT 签名验证或实时登录状态证明。额度和历史用量需用户主动查询。
- ACP 仍在独立开发分支中，不包含在本次发布。

macOS 14+（Apple silicon / Intel）：

```sh
brew update
brew install --cask vibe-agi/tap/vibermate
# 已安装时：brew upgrade --cask vibe-agi/tap/vibermate
```

Linux x86_64 / arm64 压缩包包含 Server、CLI 和 Web 工作台。请使用对应的 SHA256SUMS 文件校验下载内容。

## English

ViberMate 0.1.12 improves upstream account management and the App / Web workbench.

- Add experimental Codex OAuth login, authorization-file import, and manual credential entry. Starting login creates a link without opening a browser; remote-browser callbacks are supported.
- Manage credentials in a dedicated upstream-account registry. Services link to existing accounts without copying credentials.
- Manage Codex token refresh, including an explicit manual refresh action. Account replacement updates both Authorization and ChatGPT-Account-Id.
- Display available email, plan, and token timestamps. Query upstream quota and account history explicitly, separately from ViberMate's own usage statistics.
- Add service adapters for supported Codex account reads. Fixed-account routes use the selected account for supported quota reads; history requires separate permission, and ambiguous or dynamic routes never guess an identity.
- Add quick, searchable account notes with independent persistence, clear/edit actions, preserved drafts on save failure, and concurrency protection. Notes do not rotate credentials or change traffic-policy identity.
- Move background explanations behind accessible help controls while keeping errors, security notices, and prerequisites visible.
- Improve initial window sizing and narrow layouts. Restore the recommended size from the Window menu without discarding saved user preferences.
- Preserve cancellation causes across TLS handshake boundaries instead of reporting a misleading closed-connection error.

### Boundaries

- Codex OAuth is experimental compatibility, not an official OpenAI integration or a stable public API contract. Upstream login behavior and endpoints may change.
- Avoid concurrent refresh-token ownership after importing an authorization file. Invalidated credentials require a new login or import.
- Transparent routing does not rewrite Codex's local auth.json. Its locally displayed identity can still differ from the account selected by a route.
- Token metadata is informational, not JWT signature verification or proof of a current login. Quota and history reads are user initiated.
- ACP remains on its separate development branch and is not included.

Install or upgrade on macOS 14+ (Apple silicon / Intel) with the Homebrew commands above. Linux x86_64 and arm64 archives contain the Server, CLI, and Web workbench; verify them against the corresponding SHA256SUMS file.
