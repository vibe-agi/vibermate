# 隐藏本机身份（纯 JS，v1）

可用于现有 ViberMate 消息转换引擎。只增加脚本、构建工具和测试，不修改 Go 生产代码、
Flutter 内置示例、CLI、数据库结构、Docker 镜像或已发布策略。

**这是有明确边界的可逆文本替换，不是任意数据的全量脱敏器，也不能保证模型始终原样使用占位符。**
尤其不要在尚未验证的生产策略上直接启用；先用实际请求结构在新会话中测试。

## 使用

1. 在前端代码库中新建一个请求／响应转换条目，选择当前 AI Endpoint 的实际线协议。
   支持常见的 OpenAI Responses、Anthropic Messages、OpenAI Chat Completions 结构。
2. 将本目录的 [request.js](request.js) 全部粘贴到“请求 JavaScript”。
3. 将 [response.js](response.js) 全部粘贴到**同一个条目**的“响应 JavaScript”。
   两段代码必须共享一个转换条目的 `context`，不能拆为两个独立条目或只启用请求脚本。
4. 在测试面板提供真实结构的测试消息和合成的客户端元数据，检查发送内容及返回内容。
   保存并按现有流程发布／绑定到需要使用的流量策略；不要与旧“隐藏本机身份”示例重复绑定。
5. 用 `vibermate run` 启动新客户端会话测试。需要运行时能够提供下面三个元数据；缺失时脚本会中止请求。

已有内置示例与已发布的副本不会因修改本目录而更新；本次没有自动安装、发布或部署操作。

## 映射与隔离

只使用 Runtime 注入的客户端元数据，不相信请求正文里伪造的 `runtime` 字段：

| 客户端元数据 | 示例真实值 | 示例占位符 |
| --- | --- | --- |
| `runtime.workspace.root` | `/Users/alice/work/project` | `/__vmi1_workspace__` |
| `runtime.user.homeDirectory` | `/Users/alice` | `/__vmi1_home__` |
| `runtime.user.name` | `alice` | `⟪vmi1_user⟫` |

用户名占位符使用少见的括号字符，减少流末尾普通字母、下划线与占位符前缀的歧义。
Windows 路径保留盘符和分隔符，例如 `C:\__vmi1_workspace__`；原生路径、正斜杠形式及
`encodeURI` / `encodeURIComponent` 的标准编码形式使用可区分的占位符，以便还原原来的表示。
相同主目录与工作区根路径合并为一个映射；路径重叠时选最长、且满足边界的路径。
可编辑文本中的本地 `file:///Users/...`、`file:///C:/Users/...` 也替换已知路径，
保留 URI 前缀与原路径表示，响应时还原；不解析远程文件主机或 UNC authority。

映射只存在本条转换的 `context.vibermateLocalIdentityV1` 中，不使用全局变量、外部存储或数据库。
现有 Runtime 为每个逻辑请求／转换条目创建独立上下文，不同用户、会话、并发请求各自还原。
占位符相同不代表共享了真实值，也不是用户身份标识；它不增加新的认证／授权机制。

**每轮都会建立全部已知映射**，并不要求本轮出现真实值。因此下一轮只发送“继续”、
由上游保留历史上下文时，仍可还原同一组占位符。该保证要求客户端元数据与脚本版本不变。
更换工作区、账号、路径、脚本版本，或从旧示例迁移时，应开启新会话，不要复用携带旧占位符的远程历史。

## 修改范围

- 请求：`instructions`、`system`、消息文本、支持的文本内容块、工具结果、工具参数中的字符串值、
  自定义工具输入及工具描述。响应：支持的消息文本、拒绝文本、工具参数和自定义工具输入。
- 外层 JSON 先解析后处理；函数工具的 `arguments` 再单独解析为 JSON 对象，递归处理字符串值，
  保留数字、布尔值、空值、数组结构与键名。非流式内容无修改时保留原正文，不无故重排 JSON。
- 不修改请求地址／方法／头、状态码、模型、角色、工具名、调用 ID、会话 ID、`stream`、路由元数据、
  usage、annotations、logprobs、签名、加密推理或多媒体／二进制内容。Runtime 本身仍负责报文 framing。
- 已签名 thinking 与其签名、Responses reasoning 及其加密续接数据保持一致，不进行反向替换。
  若重新发送的这类不可编辑的明文包含可识别的真实身份，拒绝请求，不破坏签名后继续发送。
- 工具 schema 不改写。schema、未知内容块或应用 JSON 键中发现需改写的已知身份时，拒绝请求，
  不猜测如何改变工具约束或键名。非 2xx 响应（包括 HTML 错误页）保留原样。

这不是全量隐私保证：独立主机名、邮箱、IP、其他目录、外层 `metadata` / `user`、一般 URL、请求头、
文件内容、base64、加密／压缩在字符串里的内容等不在本功能的识别范围。
也不猜测任意 shell 转义、符号链接、大小写变体、URL 非标准编码或 Unicode 归一化后的路径。

匹配区分大小写并检查边界，例如 `alice` 不匹配 `malice`、`alice2`、`alice-test` 或邮箱的一部分。
短用户名以及 `root`、`admin`、`administrator`、`user`、`test`、`guest`、`system` 默认仅在
明确的用户名／登录标签或工具参数字段中替换；这避免把普通词义改坏，但意味着不能保证所有歧义用户名都被隐藏。
主目录与工作区的已知路径仍正常替换。脚本不重新解释／规范化路径，模型也应将占位符当作不透明值，
不要修改占位符、切换其编码、从虚构目录层级推导真实目录或将用户名占位符用于其他标识符。

`__vmi1_` 与 `⟪vmi1_` 是保留命名空间。可编辑的原始请求文本出现它们时会被拒绝，
避免把用户本来就写入的普通文本错误还原成另一段身份数据。旧示例的 `/workspace/project`、
`/Users/guest`、`vibermate-user` 不会被本脚本擅自解释为本轮身份。

## 流式响应

- 文本以 Responses 的输出／内容索引、Anthropic block 索引、Chat choice 索引分别保存短前缀状态，
  支持占位符跨任意多个完整 SSE 事件的 delta。普通文本即时输出，仅暂存可能构成占位符的最短必要尾部。
- 函数工具参数按工具调用分开缓冲，拼成完整 JSON 对象后解析、还原、再输出，
  避免在转义序列、字符串值和键名之间盲目替换。**工具参数增量会延迟到完整对象出现**；
  不缓冲整个回答，也不修改工具名或调用 ID。
- 同一条 Responses 流的 delta、done、item 和 completed 中可编辑的完整快照使用同一映射还原。
  SSE 的 `event` 名、事件数量、顺序与协议状态仍由 Runtime／原协议控制。
- 一个函数参数缓冲最多 16,384 个 JS UTF-16 单元，最多 32 个活动通道；映射加上下文序列化文本
  最多 24,000 个单元，同时仍受 Runtime 的 64 KiB、1024 个值、单次 2 秒等限制。
  JSON 遍历有深度与节点数上限；超出安全整数范围、会被重编码舍入的小数、负零或下溢数值也会拒绝，
  避免 JS 重编码时静默改变数字。

### 纯 JS 不能解决的收尾边界

当前 Runtime 每个 SSE 事件只调用一次响应脚本，只允许替换该事件的 data，没有生成额外事件的 API。
`[DONE]` 不传入脚本，底层 EOF 也没有 JS `finish` 回调。

因此本版本**不是任意异常流都能无损收尾**：

- 收到正常的 block／choice／response 终止事件时，如果还剩尚未输出的占位符前缀或不完整工具 JSON，
  脚本主动报错，Runtime 中止转换；不会把残缺路径作为成功结果返回。只有已经安全输出的公共前缀，
  例如 POSIX `/` 或 Windows 盘符，允许原样结束。
- 如果上游在没有正常终止事件时直接断开、只给 `[DONE]`，脚本无法获得最后一次调用。
  不能声称已检查或补回这类残留缓冲；必须依赖现有传输／协议层的失败判定，不能把它当作已实现的无损恢复。
- 若要补发最后一个 delta、支持任意 EOF flush 或更大的工具参数流，需要扩展 Runtime 的流式脚本接口。
  本次未做这项服务端修改，也不通过关闭流式、篡改终止事件类型或拼接 SSE 帧来绕过它。

## 开发与验证

`src/common.js` 是两段脚本共用的开发源码；`src/request.js` 与 `src/response.js` 是入口。
Runtime 不支持模块导入，因此构建工具将它们拼成可单独粘贴的文件。

```sh
# 在仓库根目录执行；Node 只用于生成文件，不是 Runtime 依赖。
node javascript/hide-local-identity/build.mjs
node javascript/hide-local-identity/build.mjs --check
go test ./javascript/hide-local-identity -count=1
go test -race ./javascript/hide-local-identity -count=1
```

测试直接嵌入生成的 JS，在项目真实 Goja 引擎和上下文限制下运行，使用合成数据，不调用上游模型。
包括三种协议、工具 JSON、每个占位符切分位置、并行工具、多用户并发、跨轮无命中、路径重叠、
URL／Windows／JSON 转义、保留词冲突、边界误匹配、不完整流、缓冲限制、签名保留与 SSE 逐字节拆包。
源码与生成文件必须一起维护；提交前先运行 `build.mjs --check`。

## 数据留存

映射不是加密，也不更改现有证据存储策略。该功能仅控制选定 AI 消息中的对外文本及客户端还原；
Runtime 的原始请求／响应证据仍可能保存真实身份，脚本和状态也不应写入真实密钥。
请继续按 Runtime 的访问权限、证据保留和数据卷备份策略保护这些数据。
