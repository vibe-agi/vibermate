# JavaScript 脚本目录

用于存放 ViberMate 请求与响应转换的独立 JavaScript 脚本文件，例如“隐藏本机身份”。

## 脚本

- [隐藏本机身份](hide-local-identity/README.md)：用户名、主目录、工作区根路径的请求替换与响应还原。
- [隐藏客户端元信息](hide-client-metadata/README.md)：独立的 version、install id、User-Agent 请求头替换。

各功能目录提供可直接粘贴的脚本，请按各自 README 安装。
文件放入本目录不会自动生效；使用时须配置到前端代码库，保存并绑定到相应流量策略。
“隐藏本机身份”必须将请求／响应脚本配置到同一个条目，不能只安装请求脚本；
“隐藏客户端元信息”仅有请求脚本，响应脚本留空。

此目录没有自动加载功能。当前 UI 内置示例仍定义在
`ui/flutter_app/lib/features/workbench/code_library_view.dart` 中，本次未替换该示例，也未迁移数据库中的已发布策略。

请勿在脚本中硬编码真实密钥、凭据或个人身份数据。

## 与账号管理、压缩报文的分工

- JS 处理的是 Runtime 解码后的逻辑正文，不是原始 HTTP 的 gzip/zstd 字节。
  不要在脚本中再次 Base64 解码、解压，或手动修补 `Content-Length`、`Content-Encoding`。
  Raw HTTP 保留的物理报文与可读视图并不是同一个转换输入。
- OAuth 自动／手动刷新、refresh token 保存以及 `Authorization` 与
  `Chatgpt-Account-Id` 的配对替换由账号管理负责。不要另外编写登录、刷新或改账号头的脚本。
  转换在托管鉴权前运行；账号的 Header overwrite 仍会在最终鉴权阶段应用。
- 额度／账号历史读取是独立的受控操作，不是 AI 回答，不会执行这些消息转换。
  JS 不应把原账号的 CLI 显示文字伪造成新账号，也不应自己联网查询额度。
- 账号选择脚本目前只使用传入的冻结候选与运行时上下文；不能假设 `accounts` 中已有实时额度。
  “按剩余额度择号”需要先定义有来源、时间和失效规则的只读额度数据，不能仅增加一个 JS 示例。

## 本轮模板检查（2026-09-22）

- 保留两个独立脚本；原有行为测试与生成文件一致性检查通过，不需要为 OAuth 增加凭据操作。
- UI 内置“显示轮次时间／显示返回模型”模板已增加结构化输出保护：请求声明 JSON／schema
  输出时，不往结果前添加时间或模型注解。普通文本与流式文本仍保留原有注解功能。
  **更新后的请求和响应脚本必须成对保存到同一条目**，因为格式判定通过该条目的 `context` 传递。
  如果缺少请求阶段的格式判定，响应脚本会跳过装饰，不猜测输出格式。
- 内置的简易身份替换示例仍使用全文字符串替换；实际 Codex 请求含有 schema、ID、签名、
  加密续接字段时，优先使用本目录的完整“隐藏本机身份”脚本，不要将简易示例与它重复绑定。
  后续可将这个完整实现纳入内置模板，但应保留按修订发布与显式选用的流程。
- 没有删除、自动改写或升级数据库里已发布的用户脚本。需要新行为时，请从更新模板创建／发布
  新修订，在测试面板验证后再关联到流量策略。
