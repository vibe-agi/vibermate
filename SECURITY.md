# Security Policy / 安全策略

## Report privately

Please do not open a public issue for a suspected vulnerability. Use
[GitHub private vulnerability reporting](https://github.com/vibe-agi/vibermate/security/advisories/new)
so credentials, captured content, and reproduction details remain private.

Include the ViberMate version or commit, macOS version, expected and observed
behavior, impact, and the smallest sanitized reproduction you can provide. Do
not submit real provider credentials, Root CA private keys, or unredacted
conversation data.

Security fixes target the latest public release. Older builds may require an
upgrade rather than a backport.

## 私下报告安全问题

如果你怀疑发现了安全漏洞，请不要创建公开 Issue。请使用
[GitHub 私密漏洞报告](https://github.com/vibe-agi/vibermate/security/advisories/new)，
避免凭据、捕获内容和复现细节被公开。

报告中请注明 ViberMate 版本或提交、macOS 版本、预期行为、实际行为、影响，
以及经过脱敏的最小复现步骤。请勿提交真实的服务商凭据、根证书私钥或未经
脱敏的对话内容。

安全修复以最新公开版本为目标；旧版本可能需要升级，而不会单独回补。
